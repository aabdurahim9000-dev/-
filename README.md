# Тихие воды

1. Создайте репозиторий на GitHub и загрузите все файлы этой папки (включая скрытую `.github`) в ветку `main`.
2. Вкладка **Actions** → **Build APK** сработает сама (или нажмите **Run workflow**).
3. Через 5–8 минут откройте завершённый запуск → **Artifacts** → `tikhie-vody-apk`. Внутри `app-debug.apk`.
4. Скачайте на телефон, разрешите установку из неизвестных источников, установите.

Сюжет живёт в объекте `S` в `www/index.html`. Новая сцена добавляется одной строкой.
Проверить без сборки: откройте `www/index.html` в браузере телефона.
